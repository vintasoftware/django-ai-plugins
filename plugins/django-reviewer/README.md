# Django Reviewer

A report-first reviewer for recent or user-selected Django and Python changes.
It focuses on clarity, maintainability, ORM and DRF pitfalls, and project
conventions without silently broadening the requested scope.

Portable hosts receive `portable-skills/django-reviewer/`; Claude receives the
generated agent in `agents/django-reviewer.md`. Both derive from the canonical
reviewer skill.

See the shared [installation and lifecycle guide](../../docs/installation.md).
